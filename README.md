## 🚀 The Experience

Nova Stellar isn't just a website; it's a digital odyssey. Every scroll, every transition, and every interaction is designed to evoke the feeling of weightless luxury and cosmic awe.

### ✨ Key Features

- **🌌 Cinematic Landing:** A "Big Bang" entrance with character-by-character reveal animations and dynamic nebula glows.
- **🔭 Interactive Star Map:** A curated grid of the galaxy's most exclusive destinations, featuring parallax imagery and staggered scroll reveals.
- **🤖 Astra AI Concierge:** An integrated AI assistant powered by an edge-function, providing real-time interstellar travel recommendations.
- **💳 Galactic Credit System:** A full-stack economy where users manage their credits and secure luxury bookings via a secure API pipeline.
- **🛸 Space-OS Dashboard:** A premium user profile center to track flight manifests, rank, and interstellar achievements.

## 🛠️ Tech Stack

Nova Stellar is built using a modern, production-ready stack designed for performance and scale.

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | `Next.js 15` | App Router, Server Components, Optimized Routing |
| **Animation** | `Framer Motion` | Cinematic transitions, Parallax, Layout animations |
| **Styling** | `Tailwind CSS v4` | High-performance utility-first styling |
| **Database** | `Prisma` + `SQLite` | Type-safe ORM and robust data modeling |
| **Icons** | `Lucide React` | Minimalist, professional iconography |
| **Language** | `TypeScript` | Enterprise-grade type safety |

## 🎨 Visual Identity

The design system focuses on **Contrast** and **Luminosity**.

- **Deep Space Indigo** (`#05070A`): The foundation of the void.
- **Stellar Gold** (`#D4AF37`): Representing luxury, prestige, and the light of distant stars.
- **Nebula Violet** (`#6D28D9`): Creating ethereal, organic glows and depth.
- **Glassmorphism:** High-blur surfaces that simulate futuristic control panels.

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Installation

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/your-username/nova-stellar.git
   cd nova-stellar
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Set up the database**
   \`\`\`bash
   npx prisma migrate dev --name init
   npm run seed
   \`\`\`

4. **Run the development server**
   \`\`\`bash
   npm run dev
   \`\`\`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the galaxy.
